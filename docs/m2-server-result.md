## Defect, recheck, and boundary verdict

The first exact-100 m PostGIS run exposed a real false negative in Point nearby read/write: raw `ST_DWithin(...,100)` could exclude a point projected exactly 100 m from the anchor. The production query now uses a `100.01` m GiST-compatible prefilter followed by `ST_Distance(...) <= 100` for the actual contract. An intermediate rerun passed the repository exact-100 assertion but failed a test assertion that still demanded raw `ST_DWithin(...,100)` be true; that test assertion was corrected. The final two-case radius class passed **JUnit 2/0/0/0**, covering exact-100 read and write, 100.001 m exclusion/creation, and committed DB state. The affected nearby/context/guards/block focused regressions passed again on the fixed production source with counts **1/0/0/0**, **1/0/0/0**, **2/0/0/0**, and **1/0/0/0** respectively. This resolves the observed local production defect; the initial failure remains recorded as history.
