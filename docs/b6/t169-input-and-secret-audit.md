# T169. Валидация, SQL и защита секретов в журналах

Дата — 07.11.2026. Исполнитель — Codex. Backend от `0a2ac71`, локальная схема V016.

- RED — `SessionRouteTest` обнаружил исключение в предупреждении после успешного logout. Тест ввёл синтетические JWT, пароль БД и приватный текст в сообщение `SQLException` и перехватил событие журнала. Результат logout остался 204, прежний access был отклонён.
- Правка оставляет тип исключения и контекст операции. Сообщение, cause и stack trace больше не передаются логгеру в обработчиках посткоммитных сбоев и фоновых циклов. Управление ошибками, результат мутаций и повтор задач сохранены.
- GREEN — 20 тестов, ноль ошибок и пропусков. `SessionRouteTest` подтвердил отсутствие чувствительных значений и Throwable в предупреждении. `SafeErrorEnvelopeTest` подтвердил безопасные HTTP-ответы и журналирование без SQL-текста. `PointWriteRouteTest` проверил отказ без мутации при некорректном вводе. Также выполнены `SessionAccessTest`, `ServerConfigTest` и `DeviceTokenCipherTest`.
- Проверенные пути JDBC передают параметры через prepared statements. Интерполяция в проверенных запросах относится к внутренним таблицам, предикатам и порядку, которые выбирает сервер. Примеры конфигурации содержат имена параметров, чувствительные значения задаются извне. Статический поиск по 358 отслеживаемым текстовым файлам на базовом коммите не нашёл приватных ключей, компактных JWT и форматов ключей AWS/GitHub. В `.env.example` поля credentials пусты.
- Независимый эвристический просмотр истории, достижимой из `ce8a7a3`, охватил 841 уникальный Git blob, из них 840 текстоподобных. Совпадений с форматами приватных PEM-ключей, AWS access keys, GitHub tokens и компактных подписанных JWT нет. Отслеживаемых путей `.env` в проверенной истории нет. Вывод ограничен этими шаблонами, текстоподобными объектами и достижимой историей. Значения не выводились.
- Дополнительные доказательства строгого JSON, размера, поиска и bbox собраны отдельными сценариями `SendInputIntegrationTest`, `HistorySearchIntegrationTest`, `PointMapFilterValidationIntegrationTest` и `PointCreationContextRoutesIntegrationTest`. Прогон над целевой конфигурацией и её секретами относится к этапу 5.
