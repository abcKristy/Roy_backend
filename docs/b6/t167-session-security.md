# T167. Подпись и отзыв сессий

Дата — 07.11.2026. Исполнитель — Codex. Backend от `0a2ac71`, локальная PostgreSQL 18.6, PostGIS 3.6.4 и Flyway V016. Фикстура одноразовая, `roy_m3_chat` на loopback.

- Нативный Netty REST `GET /api/v1/me` возвращает 200 для действующей сессии. Отсутствующий JWT отклоняется с 401 и `AUTH_REQUIRED`. Истёкший, отозванный, подписанный чужим ключом и неподписанный JWT возвращают 401 и `SESSION_EXPIRED`. Поддельный и неподписанный JWT несут тот же действующий user ID, jti, authVersion и срок, что и успешно принятый токен.
- Нативный WebSocket upgrade с каждым из этих недействующих токенов получает 401. Для уже открытого сокета проверены `session.revoked` и close 4401. Вторая сессия этого пользователя остаётся активной и продолжает получать свои события. Отдельная проверка на нативном транспорте подтверждает close 4401 после фактического истечения JWT.
- Ротация и повтор refresh проверяются в `JdbcRefreshRepositoryIntegrationTest`. Отзыв старого access и refresh после смены пароля подтверждён сквозным сценарием [T143](../m5-b54-b55-local-handoff.md), а отзыв всех сессий проверяет `ProfileServiceIntegrationTest`.

Результат собственного обязательного прогона — `WebSocketSubscriptionIntegrationTest` и `WebSocketLifecycleIntegrationTest`, два выполненных сценария без ошибок и пропусков. Синтетические значения токенов и ключей в протоколе отсутствуют. Повторите тесты через `integrationTest` с изолированной V016 по [инструкции](../integration-test-safety.md).
