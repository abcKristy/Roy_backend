# T172 · Приватность добровольного центра карты

Аудит backend на этапе 1, 7 ноября 2026 года. Исполнитель — Codex, локальный контур. Повторение пользовательской цепочки входит в этап 3. `policyVersion=draft-2026-11-01.2`, статус — [локальная редакция для разработки](../privacy-policy-draft.md). Синтетический пользователь получает версию через `GET /api/v1/legal/privacy` и принимает её при регистрации. Правила описывают добровольное сохранение последнего центра карты для предложений рядом. Подготовка опубликованной редакции входит в этап 4, проверка её HTTPS URL, версии, текста и согласия — в этап 5.

| Проверка | Наблюдение | Свидетельство |
| --- | --- | --- |
| NEARBY-01 · Последняя позиция | Два разных PUT одного владельца дают один ряд PostGIS. GET возвращает вторую позицию и время её записи. Чужой GET с подставленным `userId` возвращает собственное пустое состояние, PUT с чужим `userId` получает 422, DELETE с таким параметром выполняется от имени вызывающего аккаунта. У владельца сохраняется прежнее состояние. DELETE без сессии получает 401. | Свежий `MvpBackendChainIntegrationTest` по API-035–037, [каталог API](api-cases.md). |
| NEARBY-02 · Удаление | DELETE владельца возвращает 204 и удаляет ряд; GET возвращает `position=null` и `updatedAt=null`. Отключение обоих extra стирает заново записанный центр. Включение флага его не восстанавливает. Удаление аккаунта очищает повторно записанную позицию и возвращает 401 на GET со старой сессией. | Свежий `MvpBackendChainIntegrationTest`, исторические `NotificationRoutesIntegrationTest`, `NotificationServiceIntegrationTest`, `AccountDeletionPrivateCleanupIntegrationTest`. |
| NEARBY-03 · Получатели и время | При коммите нового предложения применяется расстояние до 1 000 м включительно. Точки на 999 м и 1 000 м проходят, 1 000,001 м исключается. Без сохранённого центра, актуального согласия или включённого extra получатель не выбирается. Включение настройки после исходного отбора и повтор запроса создания не добавляют события к уже созданному предложению. | `JdbcNotificationWriterIntegrationTest`, `ProposalServiceIntegrationTest`, `ProposalEventsIntegrationTest`, [RACE-010](race-cases.md). |
| NEARBY-04 · Публичный адресат | Постороннему доступна ссылка на публичную точку. `target.chatId` и `target.proposalId` имеют null. Видимое событие совпадает в REST и WS. Push-only событие исключено из REST и WS. Worker перепроверяет согласие и сохраняет публичный target в payload. | Свежий `MvpBackendChainIntegrationTest`, исторические `ProposalEventsIntegrationTest`, `JobsIntegrationTest`, `NotificationHistoryIntegrationTest`. |
